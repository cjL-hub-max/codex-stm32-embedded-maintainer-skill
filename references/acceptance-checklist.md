# 验收清单

仅在实施和最终检查阶段读取本文件。

## 编译

- [ ] 使用当前工程对应工具链完成构建，或明确说明无法构建的原因。
- [ ] 新代码 0 error。
- [ ] 原则上新代码 0 warning。
- [ ] 原工程遗留警告与本次新增警告分开说明。
- [ ] 函数声明、定义和调用一致。
- [ ] 结构体、队列元素大小和头文件引用一致。

## 架构

- [ ] `freertos.c` 只保留 RTOS 资源、任务创建和简洁任务壳。
- [ ] 主业务流程能从一个主要业务文件顺序阅读。
- [ ] 只有需要独立执行流程的功能才有任务。
- [ ] 没有新增无意义的 Manager、Service、Adapter、Helper 或 Utils 层。
- [ ] 普通业务函数通常约 50 到 120 行。
- [ ] 没有一排只含几行的包装函数。

## 命名

- [ ] 可编辑业务变量只用简单英文小写。
- [ ] 可编辑业务变量最多一个下划线。
- [ ] 下划线前后各为一个简单单词。
- [ ] 名称表达用途，必要时带简单单位。
- [ ] 受保护模块原有名称未被修改。

## 注释

- [ ] 所有变量有用途注释。
- [ ] 所有宏或命名常量有用途和必要来源注释。
- [ ] 所有结构体成员和枚举值有注释。
- [ ] 所有函数有函数头注释。
- [ ] 关键功能步骤有密集但不冗余的流程注释。
- [ ] 注释说明用途、原因、单位、方向或数据流，不机械重复语法。

## 模式

- [ ] 只使用一个主要数字变量切换运行模式。
- [ ] 模式 `switch` 集中展示主要业务支路。
- [ ] 没有多个会互相冲突的功能开关。
- [ ] 模式切换时旧命令和旧状态按当前工程需要得到处理。

## 数据流

- [ ] 每类数据有明确来源和主要写入者。
- [ ] 普通同步数据使用函数参数。
- [ ] 异步命令使用已有队列或合适 RTOS 资源。
- [ ] 传感器读取最新有效快照，避免过期控制命令积累。
- [ ] 单位、方向和时间戳语义明确。

## 日志

- [ ] 复用或建立一个统一日志入口。
- [ ] 多任务打印有互斥保护。
- [ ] 未在受保护模块中加入项目专用日志。
- [ ] 周期整机状态约每 1000 ms 输出一行。
- [ ] 模式变化、目标变化、电机命令和关键错误按事件输出。
- [ ] 日志没有按任务周期高速刷屏。

## 硬件

- [ ] 所有本次涉及的硬件接口来自当前工程或明确资料。
- [ ] GPIO、UART、TIM、DMA、NVIC 和总线配置已核对。
- [ ] 电机方向、脉冲数、限位和有效电平已核对。
- [ ] 摄像头、雷达、热成像和双板协议参数已核对。
- [ ] 没有按经验猜测配置。
- [ ] 资料冲突已经明确报告。

## 保护模块

- [ ] 可移植外设、协议、算法和通用功能模块已列出。
- [ ] 保护模块文件名、接口、类型、协议和内部布局未修改。
- [ ] 若用户明确要求修改保护模块，变更范围和移植影响已单独说明。

## FreeRTOS

- [ ] 任务保持 `while (1)` 或有明确自删除逻辑。
- [ ] 循环中存在队列阻塞、通知等待、`osDelay` 或 `vTaskDelay`。
- [ ] 任务中没有 `HAL_Delay`。
- [ ] 复杂业务不在任务壳中。
- [ ] 队列、互斥锁和任务创建位于工程约定位置。

## 电机专项

涉及电机时：

- [ ] TIM 与 DMA 句柄绑定正常。
- [ ] DMA 中断入口正常。
- [ ] TIM 比较中断入口正常。
- [ ] 电机完成回调链路正常。
- [ ] 软件位置和方向更新正常。
- [ ] 限位和安全停止逻辑正常。
- [ ] 已明确说明是否修改中断文件以及原因。

## 结果诚实性

最终结果只能表述为实际达到的状态：

- 已编译并完成指定测试。
- 已编译但需要实机验证。
- 只完成静态检查，尚未编译。
- 部分工作因明确阻塞信息未完成。
